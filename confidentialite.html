Confidentialité

Seekers de France ne vous demande rien : pas de compte, pas de formulaire, pas de cookies, pas de mesure d’audience.

Ce que l’hébergeur enregistre

Le site est hébergé par GitHub Pages. D’après GitHub, l’adresse IP des visiteurs est enregistrée et conservée pour des raisons de sécurité. Seekers de France n’a pas accès à ces données. La page de GitHub sur ce sujet

Le compteur « Solana en direct »

Sur la page Le Seeker uniquement, votre navigateur demande les chiffres du réseau Solana à PublicNode, un service public. PublicNode voit donc votre adresse IP lors de cette demande. Aucune autre information n’est envoyée.

Le reste du site

La police d’écriture, les images et le code sont servis par le site lui-même : aucun autre service n’est contacté pendant votre visite. Si vous cliquez sur un lien externe (Telegram, X, Solana Mobile…), ce sont les règles de ce site qui s’appliquent.

Vos droits

Pour toute question, écrivez dans le groupe Telegram ou à Solana Chetis sur X. Vous pouvez aussi adresser une réclamation à la CNIL.
